# TaskFlow – Kanban Task Board

Responsive Kanban board built with plain HTML, CSS and JavaScript.

## Features
- Add task: title, description, priority, due date
- Edit / delete tasks
- Move tasks between To Do, In Progress and Completed (drag and drop or dropdown)
- Search by title, filter by priority and status
- LocalStorage persistence
- Responsive desktop and mobile layout, dark mode
- Empty state, no-results state, form validation

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy on Vercel
Run `npx vercel --prod` in this folder, or import the GitHub repo on vercel.com (Framework Preset: Other).
